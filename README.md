# Portfolio Tracker (PWA)

แอปติดตามพอร์ตหุ้นส่วนตัว ติดตั้งลงมือถือได้ ราคาดึงจาก Yahoo Finance ผ่าน GitHub Actions
**จำนวนหุ้นและต้นทุนเก็บในมือถือเท่านั้น ไม่ขึ้น GitHub**

## ตั้งค่าครั้งแรก (ทำครั้งเดียว ประมาณ 10 นาที)

### 1) สร้าง repo
GitHub → New repository → ตั้งชื่อ เช่น `portfolio` → เลือก **Public** → Create repository

### 2) อัปโหลดไฟล์
ในหน้า repo กด **Add file → Upload files** แล้วลากไฟล์ทั้งหมดที่แตกจาก zip ลงไป → Commit changes
(ไฟล์: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, prices.json, symbols.json, fetch_prices.py)

### 3) สร้างไฟล์ workflow (ตัวสั่งให้ GitHub ดึงราคาอัตโนมัติ)
1. กด **Add file → Create new file**
2. ช่องชื่อไฟล์ พิมพ์ว่า `.github/workflows/update-prices.yml` (พิมพ์เครื่องหมาย / แล้ว GitHub จะสร้างโฟลเดอร์ให้เอง)
3. เปิดไฟล์ `update-prices.yml` ที่ได้ใน zip คัดลอกเนื้อหาทั้งหมดมาวาง
4. กด Commit changes

### 4) เปิด GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `/ (root)` → Save
รอ 1–2 นาที จะได้ลิงก์ประมาณ `https://ชื่อบัญชี.github.io/portfolio/`

### 5) สั่งดึงราคารอบแรก
แท็บ **Actions** → เลือก **Update prices** → **Run workflow**
(ถ้าเจอปุ่มให้ enable workflows ให้กดอนุญาตก่อน) รอสักครู่จะมี commit "update prices" ในหน้า repo

### 6) ติดตั้งลงมือถือ
เปิดลิงก์ใน Chrome บน Android → เมนู ⋮ → **ติดตั้งแอป / Add to Home screen**

## ใช้งาน
- **หน้า Overview**: รายการพอร์ต + ยอดรวมทุกพอร์ต (บาท) · ปุ่ม **+** สร้างพอร์ต
- **แตะพอร์ต**: แท็บ HOLDINGS (รายตัว) และ DETAILS (pie chart สัดส่วน) · ปุ่ม **+** เพิ่มหุ้น
- **แตะแถวหุ้น**: แก้ไข / ซื้อเพิ่ม (คำนวณต้นทุนเฉลี่ยใหม่ให้) / ขายบางส่วน / ลบ
- **⟳**: โหลดราคาล่าสุดที่ GitHub ดึงไว้ · **⋮**: Export / Import / รายชื่อหุ้น
- หัวตารางและแถบรวมด้านล่างตรึงอยู่เสมอ แตะหัวคอลัมน์เพื่อเรียงลำดับ
- ชื่อหุ้นใช้ symbol ของ Yahoo Finance เช่น `PTT.BK` (ไทย) `MC.PA` (ฝรั่งเศส) `VNM.VN` (เวียดนาม) `AAPL` (สหรัฐ) `GC=F` (ทองคำ)
- ตั้งค่าพอร์ตให้ต่อท้าย `.BK` อัตโนมัติได้ แล้วพิมพ์แค่ `PTT`
- กองทุนรวม หรือของที่ Yahoo ไม่มี: ติ๊ก **ตั้งราคาเอง** ตอนเพิ่มหุ้น แล้วมาแก้ราคาเองเมื่อต้องการ

## เมื่อเพิ่มหุ้นตัวใหม่ (สำคัญ)
ราคามาจากรายชื่อใน `symbols.json` บน GitHub ถ้าเพิ่มหุ้นใหม่ในแอป จะขึ้น "ไม่มีราคา" จนกว่าจะเพิ่มชื่อในไฟล์นั้น
วิธีง่ายสุด: แอป → ⋮ → **รายชื่อหุ้นสำหรับ symbols.json** → คัดลอก → เปิด `symbols.json` บน GitHub (กดรูปดินสอ) → ลบของเดิมแล้ววางทับ → Commit
GitHub จะดึงราคาให้ทันทีหลัง commit แล้วกด ⟳ ในแอป

## ย้ายไปเครื่องใหม่
เครื่องเก่า: ⋮ → **สำรองข้อมูล (Export)** → ดาวน์โหลดไฟล์ (หรือคัดลอกข้อความ)
เครื่องใหม่: เปิดแอป → ⋮ → **นำเข้าข้อมูล (Import)** → เลือกไฟล์ (หรือวางข้อความ)
ข้อมูลอยู่ในเบราว์เซอร์ของเครื่อง ถ้าล้างข้อมูลเบราว์เซอร์/ถอนแอป ข้อมูลจะหาย ควร Export เก็บไว้เป็นระยะ

## การใช้งานร่วมกันบนหลายอุปกรณ์
ใช้ลิงก์เดียวกัน `https://ชื่อบัญชี.github.io/portfolio/` เปิดได้ทุกเครื่อง ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

**สิ่งที่ตรงกันทุกเครื่องอัตโนมัติ** (มาจาก GitHub ที่เดียว)
- ราคา ชื่อเต็มของหุ้น อัตราแลกเปลี่ยน และข้อมูล Valuation

**สิ่งที่แยกกันในแต่ละเครื่อง** (เก็บในเบราว์เซอร์ของเครื่องนั้น ไม่ขึ้น GitHub จึงไม่ซิงค์กัน)
- พอร์ต จำนวนหุ้น และต้นทุน
- การตั้งค่ากุญแจ (ถามรหัสหรือไม่ถาม)
- สีแถบด้านบน ชื่อหน้าหลัก และรูปแบบการแสดงชื่อเต็มของหุ้น (ปุ่มรูปแถบเลื่อน)

**ทำให้ข้อมูลพอร์ตตรงกันทุกเครื่อง (ด้วยมือ)**
1. เครื่องที่มีข้อมูลล่าสุด: ⋮ → **สำรองข้อมูล (Export)** → คัดลอกข้อความ แล้วส่งให้ตัวเอง เช่น LINE หรืออีเมลของตัวเอง
2. อีกเครื่อง: เปิดข้อความนั้น → คัดลอก → เปิดแอป → ⋮ → **นำเข้าข้อมูล (Import)** → วางข้อความ
3. **ระวัง:** การนำเข้าจะ **แทนที่ข้อมูลเดิมทั้งหมด** ในเครื่องนั้น แอปจะถามยืนยันก่อนเสมอ
4. ถ้าแก้ไขพอร์ตที่เครื่องหนึ่งทีหลัง อีกเครื่องจะไม่เปลี่ยนตาม ต้องทำขั้นตอนนี้ซ้ำ ควรเลือกเครื่องหลัก 1 เครื่องไว้แก้ไขข้อมูล แล้วเครื่องอื่นใช้ดูอย่างเดียว

**เรื่องการติดตั้งลงแต่ละเครื่อง**
- แท็บเล็ตหรือคอมที่ติดตั้งแอปไม่ได้ (Chrome ขึ้นว่า "already installed" หรือ "could not open app") ให้เลือก **Create shortcut** แทน จะได้ไอคอนทางลัดบนหน้าจอหลัก ใช้งานได้ครบเหมือนกัน ต่างแค่เปิดผ่าน Chrome และยังเห็นแถบ Chrome ด้านบน
- ถ้าอัปโหลด `index.html` ตัวใหม่ขึ้น GitHub แล้ว ทุกเครื่องจะได้เวอร์ชันใหม่เอง หลังรอ 2–3 นาทีแล้วปิดแอปเปิดใหม่ (บนคอมกด Ctrl+F5)
- ถ้าเปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์ ต้องใส่รหัสผ่านครั้งแรกใหม่ และตั้งค่าหน้าตากับกุญแจใหม่

## ข้อควรรู้
- ราคาไม่ใช่ realtime: GitHub ดึงทุก 30 นาทีในวันจันทร์–ศุกร์ (บางครั้งช้าไปบ้าง) และหุ้นแต่ละตลาดอัปเดตตามเวลาเปิดทำการ
- ยอดรวมเป็นบาท แปลงหุ้นต่างประเทศด้วยอัตราแลกเปลี่ยนล่าสุด ต้นทุนก็แปลงด้วยอัตราล่าสุดเช่นกัน จึงไม่รวมกำไร/ขาดทุนจากค่าเงินตอนซื้อ
- รายชื่อหุ้นใน `symbols.json` เปิดเห็นได้ เพราะ repo เป็น public (จำนวนและต้นทุนไม่ขึ้น)
- ถ้าราคาหยุดอัปเดต: แท็บ Actions อาจถูกปิดชั่วคราวเมื่อ repo ไม่มีความเคลื่อนไหวนาน 60 วัน กดเปิดใหม่ได้ที่นั่น
- ข้อมูลราคามาจาก Yahoo Finance ผ่านช่องทางที่ไม่เป็นทางการ อาจมีบางช่วงที่ดึงไม่ได้
